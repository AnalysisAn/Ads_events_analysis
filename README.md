# Анализ рекламных событий

Проект посвящён анализу логов рекламных событий.

## Цель проекта

Провести анализ логов рекламных событий, определить причину аномального роста количества взаимодействий в один из дней и дополнительно исследовать качество логирования, CTR объявлений, распределение событий по платформам и рекламный доход.

## Задачи проекта

В проекте решаются следующие задачи:
- рассчитать ежедневную статистику по рекламным событиям: показы, клики, уникальные объявления и кампании;
- определить день с аномальным ростом количества взаимодействий и выяснить причину скачка;
- рассчитать CTR объявлений и проанализировать распределение показателя;
- проверить качество логирования событий: найти объявления с кликами без показов и случаи, когда клик произошёл раньше показа;
- сравнить показатели объявлений с видео и без видео;
- рассчитать рекламный доход по дням с учётом моделей оплаты CPC и CPM;
- проанализировать распределение показов по платформам.

## Описание данных

В проекте используется таблица с логами рекламных событий. Каждая строка соответствует одному событию: показу объявления или клику по объявлению.

Основные поля датасета:

| Поле | Описание |
|---|---|
| `ad_id` | идентификатор рекламного объявления |
| `time` | время события в формате Unix timestamp |
| `event` | тип события: `view` — показ, `click` — клик |
| `date` | дата события |
| `ad_cost_type` | модель оплаты рекламы: `CPC` или `CPM` |
| `has_video` | наличие видео в объявлении |
| `client_union_id` | идентификатор клиента |
| `campaign_union_id` | идентификатор рекламной кампании |
| `platform` | платформа, на которой произошло событие |
| `ad_cost` | стоимость рекламного действия |
| `target_audience_count` | размер целевой аудитории |
| `user_id` | идентификатор пользователя |

## Основные выводы

- В данных был найден день с аномальным ростом рекламных взаимодействий — `2019-04-05`.
- Рост связан преимущественно с активностью по одному рекламному объявлению, а не с увеличением количества объявлений или кампаний.
- Средний CTR оказался выше медианного, что говорит о неравномерном распределении показателя и наличии объявлений с высокими значениями CTR.
- В логах найдены признаки возможных ошибок: объявления с кликами без показов и нарушения последовательности событий.
- Объявления без видео в текущих данных показали более высокий CTR, однако этот вывод требует осторожной интерпретации из-за небольшой выборки видеообъявлений.
- Максимальный доход пришёлся на день аномального роста событий.
- Наибольшая доля показов приходится на платформу Android.
